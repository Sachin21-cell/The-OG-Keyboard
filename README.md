# The-OG-Keyboard
The OG Keyboard is a compact, custom-built MIDI controller designed around the Waveshare ESP32-S3-Zero microcontroller.

It features 7 piano-style capacitive touch keys made from exposed copper on the PCB that trigger notes using your body's electrical field, alongside 3 low-profile Kailh Choc mechanical switches for tactile inputs.

For real-time parameter tweaking, it includes a 10k Bourns slide potentiometer and an EC11 vertical rotary encoder with an integrated push switch.

Finishing off the design, four reverse-mounted SK6812 MINI-E Neopixel LEDs sit under the board to provide ambient RGB underglow.

It is a really good starter project which I have just tweaked with my own details!
